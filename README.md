# Sistema-De-Detecci-n-Temprana-De-Indicadores-De-Autismo-Mediante-Procesamiento-De-Im-genes-
El modelo CNN entrenado clasificó correctamente la mayoría de las imágenes del dataset, alcanzando una precisión del 86.4% al distinguir entre las dos clases: Autism (1269 imágenes) y No Autism (1270 imágenes).
